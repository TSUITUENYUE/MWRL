# mwrl

The benchmark-agnostic core of Minimal-Witness Reinforcement Learning (MWRL).

Given a context `c` and a black-box sufficiency verifier `s_c(S) ∈ {0,1}` over subsets
`S ⊆ [d]`, the minimal witnesses are the inclusion-minimal sufficient subsets — the prime
implicants of the verifier's monotone closure. They form an antichain `M(c)`. MWRL learns
one amortized policy `π_θ(· | c)` that, for a fresh context, proposes the whole antichain
with no per-instance search.

The method scores the **up-set** generated by a group of sampled witnesses rather than the
antichain directly. That turns sparse set recovery into a dense policy gradient whose
per-sample credit is the deletion marginal of a coverage valuation `V` over `2^[d]`:

```
A_i = V(U_K) − V(U_{−i})
```

where `U_K` is the up-set certified by the `K` witnesses in a group and `U_{−i}` drops
sample `i`. Dominated or failed samples receive exactly zero credit. Used directly this is
the leave-one-out estimator **l1o**; centered by a baseline from the other trajectories it
is the unbiased leave-two-out estimator **l2o** (the default).

## Modules

| File | Role |
| --- | --- |
| `env.py` | `MWRLEnv` — the environment interface the runner drives (rsl_rl-style). |
| `modules.py` | `Actor` — a masked-categorical MLP over the environment's action space. |
| `runner.py` | `Runner` — the amortized grouped score-function policy gradient. |
| `advantage.py` | The MWRL per-sample advantage for one context's group of `K` rollouts. |
| `credit.py` | The lattice-valued coverage credit and its l1o/l2o estimators. |
| `baselines.py` | Scalar group-advantage rules (maxrl, grpo, rloo) sharing the same runner. |
| `config.py` | `GroupedRLConfig` / `MWRLConfig` — the benchmark-agnostic credit contract. |

## Plugging in a benchmark

A benchmark supplies its own environment with any action and observation space. The runner
only needs, at a terminal step, the proposed witness `S` and its verifier bit `s_c(S)`. The
MaxSAT, circuits, and Suzuki benchmarks in this repository all depend only on this package.

## Install

The repository is a `uv` workspace (`requires-python >= 3.11`). From the repository root:

```bash
uv sync
```

`mwrl` is imported as a library; it has no command-line entry point of its own. See the
benchmark packages for runnable experiments.
